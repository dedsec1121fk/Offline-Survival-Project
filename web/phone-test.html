Offline-use interpretation

The core project is served only from this phone/computer. A green result means the installed browser can use that local feature. Service-worker support improves shell caching, but the local Python server remains the source of database, state and Library content.

Privacy: the diagnostic report contains browser/device capability information and the local app version. It is generated locally and is downloaded only if you choose Export.
