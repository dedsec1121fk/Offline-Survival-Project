# Κάρτα Πρώτων Πέντε Λεπτών

1. **Τι άλλαξε;** Γράψε μία πρόταση μόνο με όσα παρατηρείς άμεσα ή έχεις επιβεβαιώσει: ____________________
2. **Ποιος χρειάζεται άμεση προσοχή;** ____________________
3. **Ποια ενέργεια μειώνει τώρα τον πιο επείγοντα κίνδυνο;** ____________________
4. **Ποια επίσημη πηγή ή επιτόπιο γεγονός θα ελέγξεις στη συνέχεια;** ____________________
5. **Πότε θα επανεκτιμήσεις την κατάσταση αντί να συνεχίσεις μηχανικά το αρχικό σχέδιο;** ____________________

**Μην κάνεις ακόμη:** ______________________________________________

Η κάρτα προορίζεται για τα πρώτα λεπτά σύγχυσης. Αν αρμόδια αρχή δώσει εντολή εκκένωσης, παραμονής σε ασφαλή χώρο ή άλλη προστατευτική οδηγία, κατέγραψέ την και ακολούθησέ την χωρίς να περιμένεις να συμπληρώσεις την κάρτα.
