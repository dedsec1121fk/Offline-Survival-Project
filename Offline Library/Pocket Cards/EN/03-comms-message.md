# Low-Bandwidth Message Card

Build a message that still makes sense if only one SMS gets through.

**FROM:** __________  **TIME:** __________
**WHERE I AM:** __________________________________
**STATUS:** ______________________________________
**WHAT I NEED / DO NOT NEED:** ___________________
**NEXT MOVE:** ___________________________________
**NEXT CHECK-IN:** _______________________________

Before sending, delete speculation, repeated greetings, and details the receiver cannot act on. If delivery is uncertain, record when and by which channel you attempted it so the next person does not assume it was received.
