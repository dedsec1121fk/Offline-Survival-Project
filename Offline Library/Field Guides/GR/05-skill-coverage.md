# Κάλυψη δεξιοτήτων αντί για υποτιθέμενη ικανότητα

Ένα νοικοκυριό μπορεί να διαθέτει εξοπλισμό χωρίς να έχει περισσότερα από ένα άτομα που γνωρίζουν να τον χρησιμοποιούν. Ο πίνακας δεξιοτήτων υπάρχει για να αποκαλύπτει αυτή την εξάρτηση από ένα άτομο πριν την αποκαλύψει μια έκτακτη ανάγκη.

Κατέγραψε μια δεξιότητα μετά από πραγματική επίδειξη ή άσκηση. «Έχει εξασκηθεί» σημαίνει ότι το άτομο εκτέλεσε την εργασία σε ελεγχόμενο περιβάλλον. Η ένδειξη «Με αυτοπεποίθηση» πρέπει να βασίζεται σε πρόσφατη επιτυχημένη πρακτική και όχι σε τίτλο εργασίας ή αυτοπεριγραφή. «Μπορεί να διδάξει / επιβλέψει» είναι χρήσιμο όταν το άτομο μπορεί να εξηγήσει όρια, να παρακολουθήσει άλλον και να διορθώσει λάθη με ασφάλεια.

Δώσε ιδιαίτερη προσοχή σε σημαντικές δεξιότητες που κατέχει μόνο ένα άτομο. Στόχος δεν είναι να γίνουν όλοι ειδικοί. Στόχος είναι βασικές διαδικασίες, όπως ασφαλής διακοπή μιας γνωστής παροχής, χρήση επικοινωνιών, εντοπισμός εγγράφων, διαχείριση σακιδίου ανάγκης, φροντίδα εξαρτώμενου ατόμου ή εφαρμογή σχεδίου εκκένωσης, να μη χάνονται όταν απουσιάζει ένα πρόσωπο.
