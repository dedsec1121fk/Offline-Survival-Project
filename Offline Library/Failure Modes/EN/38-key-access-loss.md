# Failure Mode 38: Key or credential access loss

## What has changed
A key, card, code or other credential needed for a safe room, store, vehicle or building entrance is missing or cannot be used.

## Evidence to confirm
- Check physical key and spare key against the last known normal condition; write the time of the change.
- Look for a mismatch involving door code, credential card or key holder before assuming the original plan still works.
- Confirm whether lockbox and manual release provide an independent fallback rather than another dependency on the same failure.

## Decisions for the next safe step
1. Mark the failed assumption explicitly and move the immediate task away from reliance on physical key or door code.
2. Use lockbox as the first alternate only after checking that access list does not change its safety or availability.
3. Record the decision with alternate entrance and set a new review point around identity proof so the temporary workaround is not forgotten.

## Safety boundary
For key or credential access loss, preserving the old plan is never more important than avoiding a second hazard. Treat problems involving physical key, credential card or access list as reasons to stop, use an established safe alternative, and follow relevant official or professional instructions.

## Recovery checkpoint
Close this failure mode only after physical key and door code are usable again, the workaround involving lockbox has been reviewed, and the record for alternate entrance reflects what actually happened.

## Field cues
Use these concrete cues when searching notes, supplies, or related records: physical key, spare key, door code, credential card, key holder, lockbox, manual release, access list, alternate entrance, identity proof.
