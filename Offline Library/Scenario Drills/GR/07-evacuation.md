# Άσκηση Ορίου Εκκένωσης Δέκα Λεπτών

Λαμβάνεις αξιόπιστη οδηγία να εγκαταλείψεις την περιοχή. Θεώρησε ότι απομένουν δέκα λεπτά ως την αναχώρηση και ότι η άμεση επιστροφή μπορεί να μην είναι δυνατή.

Βάλε χρονόμετρο, αλλά κράτησε την άσκηση ασφαλή και μέσα στο σπίτι. Οι συμμετέχοντες μπορούν να δείχνουν ή να τοποθετούν συνηθισμένα αντικείμενα· κανείς δεν πρέπει να τρέχει σε σκάλες, να οδηγεί ή να χειρίζεται επικίνδυνο εξοπλισμό.

### Πύλες αναχώρησης
- Όλοι οι άνθρωποι/εξαρτώμενοι έχουν εντοπιστεί: ΝΑΙ / ΟΧΙ
- Απαραίτητα φάρμακα ή βοηθητικός εξοπλισμός: ΕΤΟΙΜΑ / ΟΧΙ
- Κλειδιά, ταυτοποίηση και προκαθορισμένο σύνολο εγγράφων: ΕΤΟΙΜΑ / ΟΧΙ
- Κύριος προορισμός γνωστός: ΝΑΙ / ΟΧΙ
- Εφεδρική επαφή ενημερωμένη ή μήνυμα έτοιμο: ΝΑΙ / ΟΧΙ
- Η διαδρομή ελέγχθηκε με τρέχουσα επίσημη πληροφόρηση: ΝΑΙ / ΟΧΙ

### Η δύσκολη επιλογή
Στο όγδοο λεπτό, θεώρησε ότι ένα μη απαραίτητο αλλά πολύτιμο αντικείμενο βρίσκεται ακόμη σε άλλο δωμάτιο. Εξασκήσου στο να το αφήσεις. Σημείωσε αν κάποιος προσπάθησε να μεγαλώσει τη λίστα όταν εμφανίστηκε πίεση χρόνου.

### Βελτίωσε το σύστημα
Μετέφερε ένα συχνά ξεχασμένο απαραίτητο αντικείμενο σε καλύτερη θέση ή πρόσθεσέ το στη μόνιμη λίστα αναχώρησης. Στόχος είναι αξιόπιστη εκκένωση, όχι ηρωικό ψάξιμο της τελευταίας στιγμής.
