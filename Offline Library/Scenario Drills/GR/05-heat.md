# Άσκηση Συνέχειας σε Ακραία Ζέστη

Προειδοποίηση καύσωνα δύο ημερών παρατείνεται σε πέντε. Το διαμέρισμα ζεσταίνεται περισσότερο αργά το απόγευμα, ένας ένοικος λαμβάνει φάρμακο που μπορεί να έχει απαιτήσεις αποθήκευσης και ένας ηλικιωμένος γείτονας κάνει συνήθως check-in κάθε βράδυ.

### Στρατηγική θερμοκρασίας
Εντόπισε τον πιο δροσερό χρησιμοποιήσιμο χώρο του σπιτιού, τις ώρες που παράθυρα/σκίαση βοηθούν ή επιβαρύνουν και έναν τόπο όπου θα μπορούσες να μετακινηθείς αν οι εσωτερικές συνθήκες γίνουν μη ασφαλείς. Μην θεωρείς δεδομένο ότι ανεμιστήρας ή κλιματιστικό θα λειτουργεί αν υπάρξει διακοπή ρεύματος.

### Σχέδιο για ανθρώπους
- Ποιος είναι πιο ευάλωτος στη ζέστη στο νοικοκυριό ή στο δίκτυο υποστήριξης;
- Ποια ώρα ελέγχου θα αποκάλυπτε πρόβλημα νωρίς αντί αργά τη νύχτα;
- Ποια συμπτώματα ή αλλαγή κατάστασης θα ενεργοποιούσαν επαγγελματική ιατρική βοήθεια αντί για συνέχιση διαχείρισης στο σπίτι;
- Ποιες απαιτήσεις φαρμάκου/αποθήκευσης πρέπει να επιβεβαιωθούν από ετικέτα, φαρμακοποιό ή κλινικό;

### Νέα εξέλιξη
Στις 16:30 κόβεται το ρεύμα. Βάλε ξανά σε σειρά τις προτεραιότητες ψύξης, ενυδάτωσης, επικοινωνίας και πιθανής μετακίνησης χωρίς υπόθεση για το πότε θα επιστρέψει.

Ολοκλήρωσε γράφοντας ένα σαφές όριο για μετακίνηση σε ασφαλέστερο δροσερό χώρο, βασισμένο σε παρατηρήσιμες συνθήκες και όχι στο «όταν ζεστάνει πολύ».
