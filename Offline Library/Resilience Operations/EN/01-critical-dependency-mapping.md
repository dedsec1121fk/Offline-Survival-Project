# Critical dependency mapping

## Purpose
A plan can look complete while depending on one utility, one person, one route, or one device. Dependency mapping exposes those single points of failure before an incident forces a rushed decision.

## Build the map
Start with a capability you need to keep functioning, such as communication, safe shelter, refrigeration, transport, lighting, document access, or care for a dependent. Write what that capability relies on. Continue one level deeper only when the next dependency changes what you would prepare.

For each important dependency, record the consequence of losing it, who notices the failure, and what substitute can be used. A fallback is stronger when it does not depend on the same failure source as the primary option. Two electric devices, for example, are not independent backups if both rely on the same unavailable power source.

## Review
Mark dependencies as available, degraded, unavailable, or restored. Revisit the map after a move, equipment change, seasonal hazard, household change, or failed drill. Remove obsolete entries so the register stays usable under pressure.

## Boundary
Do not create a test that requires touching damaged electrical equipment, gas systems, unstable structures, contaminated material, or any other suspected hazard. Record safely observable facts and use the appropriate authority or qualified professional when technical assessment is required.
