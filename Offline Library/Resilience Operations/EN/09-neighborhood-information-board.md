# Neighborhood information board

## Purpose
In a local disruption, rumors can move faster than verified information. A neighborhood information board creates one small place for facts, sources, time stamps, unresolved questions, and the next scheduled update.

## Information categories
Separate confirmed official information, directly observed local facts, reports that still need verification, and requests for help. Record when each item was last checked. A statement without a source or observation time should not silently become “confirmed” because it has been repeated.

## Posting discipline
Keep messages short enough to scan. Include the location or scope when it matters, but avoid exposing private household details. Correct an obsolete item visibly rather than merely adding a contradictory note below it.

## Offline operation
The board can be a printed sheet, notebook page, whiteboard, or local-device screen. Choose a fallback that works without network connectivity and define who is allowed to mark official information as verified.

## Safety
Do not publish names of vulnerable people, exact locations of valuable supplies, security arrangements, medical details, or unverified accusations. For evacuation, public safety, utilities, weather hazards, and other official matters, preserve the original issuing authority and time so readers can distinguish guidance from local commentary.
