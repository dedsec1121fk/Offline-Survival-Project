# Αποτυχία Ρόλου Νοικοκυριού

1. Εντόπισε κάθε εργασία που σήμερα έχει μόνο ένα ικανό άτομο.
2. Όρισε εφεδρικό για επικοινωνίες, υποστήριξη προσβασιμότητας, φροντίδα ζώων, μεταφορά, έγγραφα και άλλους κρίσιμους ρόλους.
3. Γράψε τις ελάχιστες οδηγίες που χρειάζεται ο εφεδρικός· μην βασίζεσαι μόνο σε προφορική γνώση.
4. Στις ασκήσεις, αφαίρεσε σκόπιμα έναν κύριο υπεύθυνο και δοκίμασε την εναλλακτική.
5. Κατέγραψε εργασίες που σταμάτησαν επειδή πρόσβαση, γνώση ή εξοπλισμός ανήκαν σε ένα άτομο.
6. Ενημέρωσε τον πίνακα ρόλων μετά από κάθε πραγματικό συμβάν ή άσκηση.
