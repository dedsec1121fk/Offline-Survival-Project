# Timekeeping during a long outage: preserve sequence when clocks, networks and sleep cycles drift

## Accurate time supports every other log
Medication schedules, check-ins, food cold-chain decisions, generator runtime and official warnings depend on knowing when something happened. Keep at least one independent clock/watch that does not require network time and know whether it uses replaceable or rechargeable power.

## Establish an incident time reference
At the start, note local date/time and the source used to verify it. If phones lose network synchronization, use the designated reference clock for logs. Avoid mixing devices with different incorrect times without noting the offset.

## Use simple shift blocks
For overnight monitoring or care, define who is responsible during each block and the exact handover time. Do not create excessively short rotations that destroy sleep. The shift schedule should include protected rest, meals and a backup person.

## Time-stamp official instructions
Write the time a 112 alert, utility notice or evacuation instruction was received. A later update can reverse or supersede it. Keeping both timestamps prevents the household from acting on an older instruction because it was printed or screenshotted.

## Track duration explicitly
Instead of saying “the freezer has been off all day,” calculate from the recorded outage start. For batteries/fuel, log runtime. Duration estimates become more accurate after each event and improve v6/v7 calculators.

## Reset when normal time sources return
Compare the reference clock to restored network/broadcast time and note any difference before correcting old records. This preserves the meaning of the incident timeline.
