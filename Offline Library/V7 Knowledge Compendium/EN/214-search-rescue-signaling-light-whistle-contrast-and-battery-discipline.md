# Search-and-Rescue Signaling: Light, Whistle, Contrast, and Battery Discipline

Being findable is a survival system. Signals should increase the chance that a rescuer detects you without consuming all power, causing fire, or requiring repeated risky movement.

## Make location easier to describe
Record coordinates and the coordinate format, last known road/trail, visible landmarks, elevation if known, group size and hazards around the site. Send the compact message early when coverage appears. Do not continuously stream media if it drains the only communication battery.

## Use layered signals
A whistle can carry farther than a voice with much less effort. A flashlight can be used deliberately at night. High-contrast fabric/marker material can make a static location easier to see. A signal mirror can be useful in sunlight if the user understands safe aiming and does not direct glare at nearby drivers/aircraft indiscriminately.

## Avoid dangerous signal fires
Do not create open flame in wildfire conditions, fuel-contaminated areas, dry grass or where fire restrictions prohibit it. Smoke/fire can create a second emergency. Prefer non-fire methods unless trained local guidance explicitly supports a signal fire.

## Preserve a signaling reserve
Keep one light and one communication device from being consumed by entertainment/general use. Use scheduled check windows rather than leaving every radio/device transmitting. Mark the planned signal schedule in the route card.
