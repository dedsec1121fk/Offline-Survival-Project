# Evacuation Bag: Fit, Weight, and a Real Walking Test

A go-bag is useful only if the intended person can actually carry it through the likely route. Lists tend to grow; shoulders, stairs, heat, children, mobility aids and evacuation speed impose real limits.

## Build by function, then weigh
Group contents by water, food, medical, communications, documents, clothing/shelter, lighting and hygiene. Remove unnecessary duplicates. Weigh the packed bag rather than estimating. Record what is externally attached because swinging bottles/tools can change balance and snag on doors or vegetation.

## Fit the user
Adjust shoulder straps and hip belt if the pack has one. Heavy dense items should not pull the user backward or sit where they create painful pressure. A child, older adult or person with mobility/respiratory limitations may need a deliberately lighter role and more supplies distributed to another carrier or vehicle.

## Test the real route
Walk with the actual bag on a safe day: stairs, the first part of the evacuation route and the expected pace. Note hot spots, handrail conflicts, whether the bag interferes with a cane/walker, and whether the user can still carry a child or control an animal if that is part of the plan. Repack after the test.

## Protect access priority
Emergency medication, identification, phone/power, water and a light should not be buried under rarely used items. Use consistent pockets so another household member can retrieve critical gear. Waterproof essential documents/electronics inside the pack rather than assuming the outer fabric is waterproof.

## Trigger for splitting the load
If one bag becomes too heavy, create modular grab units: personal bag, medical module, document pouch, animal kit, vehicle-only module. A bag left behind because nobody can carry it has zero survival value.
