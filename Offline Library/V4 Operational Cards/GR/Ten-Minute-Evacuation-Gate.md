# Όριο Εκκένωσης Δέκα Λεπτών

1. Χρησιμοποίησε τις επίσημες οδηγίες εκκένωσης ως κύριο σήμα· μην καθυστερείς υποχρεωτική εκκένωση για να ολοκληρώσεις λίστα.
2. Έλεγξε κάθε άτομο, εξαρτώμενο μέλος και ζώο πριν μοιραστούν οι εργασίες.
3. Πάρε το ήδη προετοιμασμένο σύνολο πρώτης αρπαγής αντί να ψάχνεις αντικείμενα χαμηλής προτεραιότητας.
4. Επιβεβαίωσε κύρια και εναλλακτική διαδρομή με τις τρέχουσες επίσημες πληροφορίες όπου υπάρχουν.
5. Στείλε ένα σύντομο check-in στην καθορισμένη επαφή αν λειτουργούν οι επικοινωνίες.
6. Σημείωσε ώρα αναχώρησης και προορισμό στο Ημερολόγιο Συμβάντος.
