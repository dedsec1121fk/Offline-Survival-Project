# Communications Blackout

1. Switch from repeated calling to the pre-agreed fallback methods and check-in times.
2. Preserve battery by batching message attempts and reducing unnecessary screen/radio use.
3. Write down verified information, source, and timestamp so rumor is not mistaken for an official update.
4. Use short status-location-action messages when bandwidth is limited.
5. If separated, follow the agreed meeting-point rules unless official safety instructions require a change.
6. When service returns, reconcile missed messages before changing the plan.
