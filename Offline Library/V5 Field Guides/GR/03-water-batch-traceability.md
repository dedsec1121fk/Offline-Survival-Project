# Ιχνηλασιμότητα παρτίδων νερού

Όταν πολλά δοχεία γεμίζουν σε διαφορετικές ώρες ή από διαφορετικές πηγές, η μνήμη είναι αδύναμος μηχανισμός ελέγχου. Δώσε σε κάθε παρτίδα σαφή πηγή, περίπου όγκο, δοχείο και τρέχουσα κατάσταση.

Η κατάσταση πρέπει να περιγράφει τη ροή εργασίας και όχι να ισχυρίζεται εργαστηριακή ασφάλεια:
- **Ανεξέταστο / χωρίς επεξεργασία**: η παρτίδα δεν έχει ολοκληρώσει τη μέθοδο που σκοπεύεις να χρησιμοποιήσεις.
- **Σε επεξεργασία / αναμονή**: βρίσκεται σε εξέλιξη επαληθευμένη διαδικασία ή δεν έχει ολοκληρωθεί απαιτούμενος χρόνος αναμονής.
- **Αποδεκτό για την προβλεπόμενη χρήση**: ολοκλήρωσες τη μέθοδο που επέλεξες και κρατάς την παρτίδα χωριστά για αυτή τη χρήση.
- **Απορρίφθηκε / απομονώθηκε**: δεν σκοπεύεις να χρησιμοποιήσεις την παρτίδα και δεν πρέπει να αναμειχθεί ξανά με αποδεκτό απόθεμα.

Μην αντιγράφεις δοσολογίες επεξεργασίας από μνήμης μέσα στην καταγραφή. Διαφορετικοί ρύποι, προϊόντα και μέθοδοι απαιτούν διαφορετικές οδηγίες. Η καταγραφή υπάρχει για να αποφεύγονται μπερδέματα και να διατηρείται η ιχνηλασιμότητα, όχι για να αποφασίζει αν μια επεξεργασία είναι ιατρικά επαρκής.
