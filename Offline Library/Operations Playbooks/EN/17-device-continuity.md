# Offline Device Continuity

A phone full of useful files is not an offline tool if its battery, cable, unlock method or storage fails.

### Designate roles for devices
Choose which device is primary communications, which holds offline references/maps, which may be used for navigation, and which stays mostly powered down as reserve. The same phone can fill several roles, but that concentration should be visible in the plan.

### Prove offline access
Enable airplane mode and open the critical files from storage. Test search, maps/routes, contact information and any local application you intend to rely on. Record where the files live so a second person can find them.

### Charging chain
Inventory the exact cables/adapters required from source to device. Test them with the actual power banks or chargers. Label unusual connectors and keep a known-working spare for the most important device.

### Reduce silent battery loss
Disable unnecessary radios/background activity where appropriate, lower screen demand and set deliberate check windows. Keep one paper layer—contact numbers, meeting points, essential instructions—because an offline digital plan should degrade gracefully when hardware fails.
