# Όρια Αμοιβαίας Βοήθειας με Γείτονες

## Καθόρισε τη σχέση πριν από την κρίση
Η αμοιβαία βοήθεια λειτουργεί καλύτερα όταν οι προσδοκίες είναι σαφείς. Συζήτησε τι είναι διατεθειμένο να μοιραστεί κάθε νοικοκυριό, τι παραμένει ιδιωτικό, πώς θα γίνεται η επικοινωνία και ποιες καταστάσεις δικαιολογούν έλεγχο του άλλου. Μην υπόσχεσαι ιατρικές, διασωστικές ή τεχνικές δυνατότητες που κανείς δεν διαθέτει πραγματικά.

## Ικανότητες αντί για ευαίσθητα αποθέματα
Είναι χρήσιμο να γνωρίζεις ότι ένα νοικοκυριό έχει ραδιόφωνο με μπαταρία, άλλο διαθέτει γλωσσικές δεξιότητες και άλλο μπορεί να βοηθήσει στη μετακίνηση ατόμου με περιορισμένη κινητικότητα. Συνήθως δεν χρειάζεται να γνωστοποιούνται ακριβείς ποσότητες μετρητών, φαρμάκων, καυσίμων ή πολύτιμου εξοπλισμού. Μοιράσου αρκετή πληροφορία για συντονισμό χωρίς να δημιουργείς νέο πρόβλημα ασφάλειας ή ιδιωτικότητας.

## Απλό πρωτόκολλο επικοινωνίας
Συμφώνησε χρονικό παράθυρο, κύριο τρόπο επικοινωνίας, εφεδρεία και τι σημαίνει «καμία απάντηση». Μια χαμένη επικοινωνία πρέπει να οδηγεί σε ανάλογο έλεγχο και όχι σε άμεσες υποθέσεις. Σε επίσημη εκκένωση κανείς δεν πρέπει να παραμένει σε κίνδυνο μόνο για να ολοκληρώσει το πρωτόκολλο γειτονιάς.

## Ιχνηλασιμότητα δανεισμού
Για επαναχρησιμοποιούμενο εξοπλισμό σημείωσε ποιος τον πήρε, πότε, σε ποια κατάσταση και αν δόθηκε μαζί φορτιστής ή εξάρτημα. Για αναλώσιμα αποφάσισε αν πρόκειται για προσφορά ή αναμενόμενη αντικατάσταση. Καθαρές σημειώσεις αποτρέπουν διαφωνίες όταν όλοι είναι κουρασμένοι και αναρρώνουν.

## Σεβασμός περιορισμών
Αλλεργίες, ανάγκες προσβασιμότητας, ζώα, πολιτισμικές απαιτήσεις, ευθύνες προστασίας και ιδιωτικότητα μπορούν να κάνουν ακατάλληλη μια φαινομενικά απλή κοινή λύση. Ρώτησε πριν μετακινήσεις εφόδια ή ανθρώπους στον χώρο άλλου νοικοκυριού.

## Καθαρή λήξη της προσωρινής συμφωνίας
Όταν επανέλθουν οι υπηρεσίες, τακτοποίησε δανεισμένα αντικείμενα, αφαίρεσε παρωχημένα στοιχεία επικοινωνίας, αξιολόγησε τι λειτούργησε και κράτησε μόνο τις συμφωνίες που εξακολουθούν να θέλουν τα νοικοκυριά. Η συνεργασία έκτακτης ανάγκης δεν πρέπει να μετατρέπεται κατά λάθος σε μόνιμη υποχρέωση.
