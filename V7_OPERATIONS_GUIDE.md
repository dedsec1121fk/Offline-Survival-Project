# V7 Operations Guide

Use the project in layers rather than trying to read everything during an emergency.

1. **Immediate hazard:** use Emergency Mode and current official warnings if communications are available.
2. **Stabilize the household:** check people, medical continuity, water, shelter, fire/CO safety, sanitation and communications.
3. **Build the operating picture:** update inventory, resources, power, transport, check-ins, decisions, costs and incident observations.
4. **Plan the next operational period:** use the Situation/Shift brief, decision review times, route/waypoint planning and communication windows.
5. **Study the gap:** use the Knowledge Atlas risk queue or local Library search to open the most relevant chapter.
6. **Fallback:** if the full Command Center is unnecessary, use `Offline Survival Reader.html` for the complete 220-subject bilingual compendium.
7. **After the incident:** preserve useful evidence, review decisions, update plans and remove assumptions that are no longer valid.

The 220-subject compendium is intentionally a reference set rather than a substitute for live command. Current evacuation orders, weather warnings, public-health instructions and emergency-service directions take priority whenever they can be received.

On a phone, use `--web` to open the Command Center in the installed/default browser and `--phone-browser-test` to verify the actual phone browser environment. The diagnostics report is local and should be run on the target device after installation or after a major browser/OS update.

# Οδηγός επιχειρησιακής χρήσης V7

Χρησιμοποίησε το έργο σε επίπεδα αντί να προσπαθήσεις να διαβάσεις τα πάντα μέσα σε ένα επείγον περιστατικό.

1. **Άμεσος κίνδυνος:** χρησιμοποίησε το Emergency Mode και τις τρέχουσες επίσημες προειδοποιήσεις όταν υπάρχουν επικοινωνίες.
2. **Σταθεροποίηση νοικοκυριού:** έλεγξε ανθρώπους, ιατρική συνέχεια, νερό, καταφύγιο, ασφάλεια φωτιάς/μονοξειδίου άνθρακα, υγιεινή και επικοινωνίες.
3. **Δημιουργία επιχειρησιακής εικόνας:** ενημέρωσε inventory, πόρους, ενέργεια, μεταφορές, check-ins, αποφάσεις, κόστη και παρατηρήσεις συμβάντος.
4. **Σχεδιασμός επόμενης περιόδου:** χρησιμοποίησε Situation/Shift brief, χρόνους επανεξέτασης αποφάσεων, σχεδιασμό διαδρομής/waypoints και παράθυρα επικοινωνίας.
5. **Μελέτη του κενού:** χρησιμοποίησε τη σειρά κινδύνων του Άτλαντα Γνώσης ή την τοπική αναζήτηση Library για να ανοίξεις το πιο σχετικό κεφάλαιο.
6. **Εφεδρική λειτουργία:** αν δεν χρειάζεται το πλήρες Command Center, χρησιμοποίησε το `Offline Survival Reader.html` για ολόκληρη τη δίγλωσση συλλογή 220 θεμάτων.
7. **Μετά το συμβάν:** διατήρησε χρήσιμα αποδεικτικά στοιχεία, αξιολόγησε αποφάσεις, ενημέρωσε τα σχέδια και αφαίρεσε παραδοχές που δεν ισχύουν πλέον.

Η συλλογή 220 θεμάτων είναι σκόπιμα σύνολο αναφοράς και όχι υποκατάστατο ζωντανής διοίκησης. Τρέχουσες εντολές εκκένωσης, προειδοποιήσεις καιρού, οδηγίες δημόσιας υγείας και οδηγίες υπηρεσιών έκτακτης ανάγκης έχουν προτεραιότητα όταν μπορούν να ληφθούν.

Σε τηλέφωνο, χρησιμοποίησε `--web` για άνοιγμα του Command Center στον εγκατεστημένο/προεπιλεγμένο browser και `--phone-browser-test` για να επαληθεύσεις το πραγματικό περιβάλλον browser της συσκευής. Η αναφορά διαγνωστικών παραμένει τοπική και είναι χρήσιμο να εκτελείται στη συσκευή-στόχο μετά την εγκατάσταση ή μετά από μεγάλη ενημέρωση browser/λειτουργικού.
